## 🔄 Traversal Techniques

### Binary Tree Traversals

```text
Inorder
LEFT → ROOT → RIGHT

Preorder
ROOT → LEFT → RIGHT

Postorder
LEFT → RIGHT → ROOT
```

### BST

For a Binary Search Tree:

```text
Smaller value → LEFT
Greater value → RIGHT
Duplicate value → Not inserted
```

An **Inorder traversal of a BST produces values in ascending order**.
